# `doc-hierarchy` — POC 2: document dependency tracing

**Scope:** the `doc-hierarchy` feature only. Assumes the shared `rag-api` and workspace setup
from `000.hackathon-setup.md` are already in place.

**The idea:** engineering documents form a dependency tree (A feeds B feeds C). Once reviewed
and signed off, the folder is frozen as a baseline. On the next iteration, if document A
changes, trace every downstream document that might be affected, surface what specifically
needs updating, and notify the owners.

---

## Folder structure

```
doc-hierarchy/
├── package.json
├── current-baseline.txt      # one line, e.g. "baseline1" — which folder is live
├── docs/                     # gitignored, see 000.hackathon-setup.md
│   ├── baseline1/            # frozen: *.docx + manifest.json
│   └── draft2/                # candidate next baseline, not yet promoted
└── src/{createIndex.ts, currentBaseline.ts, ingest.ts, graph.ts, detectChange.ts, mcpServer.ts}
```

---

## Key design decisions (and why)

- **Impact tracing is graph traversal, not vector search.** "What's downstream of doc A" is
  answered by BFS over declared `dependsOn` edges — deterministic, auditable. Vector search's
  job is narrower: *what* in an already-identified downstream doc might need changing. Don't
  blur the two.
- **Document metadata is an in-body table**, not `docProps/custom.xml`. `mammoth` is already a
  dependency for text extraction and renders tables via `convertToHtml`, so no extra
  unzip/XML-parse step — and anyone can open the file and see the metadata without special
  tooling.
- **Change detection is a text diff, not Word's native Compare.** `Application.CompareDocuments`
  is real but Windows/Word-desktop/COM-only. `mammoth` + the `diff` package's `diffLines` is
  cross-platform and fits the pipeline's shape (string in, string out). Swap to `diffWords` for
  finer granularity if paragraph-level is too coarse later.
- **Which baseline is "current" is a one-line pointer file** (`current-baseline.txt`), not a
  copied/symlinked "main" folder. Numbered baseline folders stay frozen and untouched;
  promoting just edits the pointer. `manifest.json` lives inside each baseline folder (not
  top-level) so a baseline's graph is frozen along with its docs, never edited out-of-band.
- **Paths resolve against `packageRoot`** (`fileURLToPath(new URL("..", import.meta.url))`),
  never `process.cwd()`. MCP clients launch servers from their own working directory — Claude
  Desktop on Windows uses `C:\Windows\System32` — so any relative path would otherwise resolve
  there. `resolveDocPath` additionally refuses anything that resolves outside `docs/`, since
  `detect_change`'s paths come from whatever the calling model supplies, not just from you.
- **`SearchClient` is explicitly typed** (`SearchClient<HierarchyDoc>`). Left untyped,
  `deleteDocuments`'s key parameter resolves to `never` and the stale-chunk cleanup call
  doesn't compile.
- **OData filter values are escaped before interpolation** (`'` → `''`). Cheap defense against
  a stray apostrophe breaking the query, and necessary once a filter value (`docId` in
  `suggest_changes`) comes from the model rather than from a document you authored.
- **`parseMetadata` validates required fields on parse**, naming whichever column is missing,
  rather than failing later with an opaque `TypeError` deep in a `.split()`.
- **`source` is stored as a repo-relative, forward-slash path**, never an absolute filesystem
  path — keeps the index portable across machines and OSes.
- **MCP stdio servers log to `stderr`, never `stdout`.** `console.log` corrupts the JSON-RPC
  transport; `console.error` shows up in the client's MCP logs. `notify_owner`'s stub logging
  follows this.
- **`RAG_API_URL` is read from an environment variable**, defaulting to
  `http://localhost:8000/search`.

## Open decisions (not yet settled)

- **Which POC becomes the actual hackathon submission** and **`wiki-freshness` naming** — see
  `000.hackathon-setup.md`; both are cross-cutting, not specific to this feature.

## Sample data

`current-baseline.txt` (→ `baseline1`) + `docs/baseline1/` + `docs/draft2/`, each baseline
folder carrying its own `manifest.json` — five synthetic railway requirement docs
(`SYS-REQ-001` → `SUB-SIG-010`/`SUB-TRAC-020` → `CMP-SIG-101` → `TST-SIG-201`), each with the
Field|Value metadata table `ingest.ts` expects (`Document ID`, `Title`, `Owner`, `Reviewer`,
`Depends On`, `Signoff Date`, `Status`). `draft2` is `baseline1` copied forward with one real
edit: `SYS-REQ-001`'s braking-distance requirement, 800m → 750m — enough to exercise
`detectChange` → `traceImpact` → `suggestChanges` end to end. Promoting `draft2` to a real
baseline later is: rename the folder `baseline2`, update `current-baseline.txt`, re-run
`ingest.ts`.

`docs/` here is gitignored — see `000.hackathon-setup.md` for what that means in practice.

## `doc-hierarchy/src/currentBaseline.ts`

The one thing `ingest.ts` and `graph.ts` both read; promoting a baseline is editing
`current-baseline.txt`, nothing else.
```ts
import fs from "node:fs";
import path from "node:path";
import { fileURLToPath } from "node:url";

export const packageRoot = fileURLToPath(new URL("..", import.meta.url));

export function getCurrentBaselineDir(): string {
  const name = fs.readFileSync(path.join(packageRoot, "current-baseline.txt"), "utf-8").trim();
  return path.join(packageRoot, "docs", name);
}

/**
 * Resolve a caller-supplied path against the package root, and refuse anything that resolves
 * outside docs/. These paths come from whatever the calling model supplies via an MCP tool
 * call, not just from you.
 */
export function resolveDocPath(p: string): string {
  const resolved = path.isAbsolute(p) ? path.resolve(p) : path.resolve(packageRoot, p);
  const docsRoot = path.resolve(packageRoot, "docs");
  if (resolved !== docsRoot && !resolved.startsWith(docsRoot + path.sep)) {
    throw new Error(`Path escapes docs/: ${p}`);
  }
  return resolved;
}
```

## `doc-hierarchy/src/ingest.ts`
```ts
import { config } from "dotenv";
config({ path: new URL("../../.env", import.meta.url) });

import fs from "node:fs";
import path from "node:path";
import mammoth from "mammoth";
import { pipeline, type FeatureExtractionPipeline } from "@huggingface/transformers";
import { SearchClient, AzureKeyCredential } from "@azure/search-documents";
import { getCurrentBaselineDir, packageRoot } from "./currentBaseline.js";

type HierarchyDoc = {
  id: string;
  docId: string;
  content: string;
  source: string;
  owner: string;
  reviewer: string;
  dependsOn: string[];
  embedding: number[];
};

const client = new SearchClient<HierarchyDoc>(
  process.env.AZURE_SEARCH_ENDPOINT!, "doc-hierarchy-index",
  new AzureKeyCredential(process.env.AZURE_SEARCH_KEY!)
);

let extractorPromise: Promise<FeatureExtractionPipeline> | undefined;
async function embed(text: string): Promise<number[]> {
  extractorPromise ??= pipeline("feature-extraction", "Xenova/all-MiniLM-L6-v2");
  const extractor = await extractorPromise;
  return Array.from((await extractor(text, { pooling: "mean", normalize: true })).data as Float32Array);
}

function odataEscape(s: string): string {
  return s.replace(/'/g, "''");
}

// Every doc starts with a Field | Value table: Document ID, Title, Owner,
// Reviewer, Depends On, Signoff Date, Status.
function parseMetadata(html: string) {
  const rows = [...html.matchAll(/<tr>(.*?)<\/tr>/gs)].map(m =>
    [...m[1].matchAll(/<td[^>]*>(.*?)<\/td>/gs)].map(c => c[1].replace(/<[^>]+>/g, "").trim())
  );
  const map = Object.fromEntries(rows.map(([k, v]) => [k, v]));

  const required = ["Document ID", "Owner", "Reviewer", "Depends On"] as const;
  const missing = required.filter(f => map[f] === undefined);
  if (missing.length) {
    throw new Error(`Metadata table missing field(s): ${missing.join(", ")}`);
  }

  return {
    docId: map["Document ID"],
    owner: map["Owner"],
    reviewer: map["Reviewer"],
    dependsOn: map["Depends On"] === "—" ? [] : map["Depends On"].split(",").map(s => s.trim()),
  };
}

function chunk(text: string, size = 1000): string[] {
  const out: string[] = [];
  for (let i = 0; i < text.length; i += size) out.push(text.slice(i, i + size));
  return out;
}

async function ingestFile(filePath: string) {
  const { value: html } = await mammoth.convertToHtml({ path: filePath });
  const { value: text } = await mammoth.extractRawText({ path: filePath });
  const meta = parseMetadata(html);

  // Deterministic per-doc IDs + delete-before-upload: re-ingesting the same docId (a new
  // baseline, a re-run) replaces its chunks cleanly instead of accumulating duplicates or
  // leaving orphaned chunks behind when content shrinks.
  const stale = await client.search("*", { filter: `docId eq '${odataEscape(meta.docId)}'`, select: ["id"] });
  const staleIds: string[] = [];
  for await (const r of stale.results) staleIds.push(r.document.id);
  if (staleIds.length) await client.deleteDocuments("id", staleIds);

  const chunks = chunk(text);
  const documents = await Promise.all(chunks.map(async (c, i) => ({
    id: `${meta.docId}-${i}`,
    docId: meta.docId,
    content: c,
    source: path.relative(packageRoot, filePath).split(path.sep).join("/"),
    owner: meta.owner,
    reviewer: meta.reviewer,
    dependsOn: meta.dependsOn,
    embedding: await embed(c),
  })));
  await client.uploadDocuments(documents);
  console.log(`Indexed ${documents.length} chunks from ${meta.docId}`);
}

const baselineDir = process.argv[2] ? path.resolve(packageRoot, process.argv[2]) : getCurrentBaselineDir();
for (const f of fs.readdirSync(baselineDir).filter(f => f.endsWith(".docx"))) {
  await ingestFile(path.join(baselineDir, f));
}
```
Run: `npm run doc-hierarchy:ingest` — ingests whatever `current-baseline.txt` points to. Pass a
folder explicitly (`npm run doc-hierarchy:ingest -- docs/draft2`) to index a not-yet-promoted
draft for testing without touching the pointer.

**Chunking here is a fixed 1000 characters** (can split mid-sentence, folds the metadata table
into the first chunk for short docs) — accepted as-is while documents are ~1 chunk each.
`docs-search`'s ingest is paragraph-aware instead; not needed here yet.

## `doc-hierarchy/src/graph.ts`
```ts
import fs from "node:fs";
import path from "node:path";
import { getCurrentBaselineDir } from "./currentBaseline.js";

type Edge = { docId: string; dependsOn: string[] };

export async function loadGraph(): Promise<Edge[]> {
  const file = path.join(getCurrentBaselineDir(), "manifest.json");
  return JSON.parse(await fs.promises.readFile(file, "utf-8"));
}

export function downstreamOf(graph: Edge[], changedDocId: string): string[] {
  const affected = new Set<string>();
  const queue = [changedDocId];
  while (queue.length) {
    const current = queue.shift()!;
    for (const doc of graph) {
      if (doc.dependsOn.includes(current) && !affected.has(doc.docId)) {
        affected.add(doc.docId);
        queue.push(doc.docId);
      }
    }
  }
  return [...affected];
}
```

## `doc-hierarchy/src/detectChange.ts`
```ts
import mammoth from "mammoth";
import { diffLines } from "diff";

export async function detectChange(baselinePath: string, draftPath: string): Promise<string | null> {
  const [{ value: oldText }, { value: newText }] = await Promise.all([
    mammoth.extractRawText({ path: baselinePath }),
    mammoth.extractRawText({ path: draftPath }),
  ]);
  if (oldText === newText) return null;

  return diffLines(oldText, newText)
    .filter(p => p.added || p.removed)
    .map(p => `${p.added ? "+ " : "- "}${p.value.trim()}`)
    .join("\n");
}
```

## `doc-hierarchy/src/mcpServer.ts`
```ts
import { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js";
import { StdioServerTransport } from "@modelcontextprotocol/sdk/server/stdio.js";
import { z } from "zod";
import { loadGraph, downstreamOf } from "./graph.js";
import { detectChange } from "./detectChange.js";
import { resolveDocPath } from "./currentBaseline.js";

const RAG_API_URL = process.env.RAG_API_URL ?? "http://localhost:8000/search";
const INDEX = "doc-hierarchy-index";
const server = new McpServer({ name: "doc-hierarchy", version: "1.0.0" });

function odataEscape(s: string): string {
  return s.replace(/'/g, "''");
}

server.registerTool(
  "detect_change",
  {
    description: "Diff a document's baseline copy against its draft copy.",
    inputSchema: { docId: z.string(), baselinePath: z.string(), draftPath: z.string() },
  },
  async ({ baselinePath, draftPath }) => {
    const summary = await detectChange(resolveDocPath(baselinePath), resolveDocPath(draftPath));
    return { content: [{ type: "text" as const, text: summary ?? "No changes detected." }] };
  }
);

server.registerTool(
  "trace_impact",
  {
    description: "Given a changed document ID, return all documents downstream of it.",
    inputSchema: { docId: z.string() },
  },
  async ({ docId }) => {
    const graph = await loadGraph();
    const affected = downstreamOf(graph, docId);
    return { content: [{ type: "text" as const, text: affected.length ? affected.join(", ") : "No downstream documents found." }] };
  }
);

server.registerTool(
  "suggest_changes",
  {
    description: "Suggest what might need updating in a downstream doc given an upstream change summary.",
    inputSchema: { docId: z.string(), changeSummary: z.string() },
  },
  async ({ docId, changeSummary }) => {
    const res = await fetch(RAG_API_URL, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ index: INDEX, query: changeSummary, top_k: 5, filter: `docId eq '${odataEscape(docId)}'` }),
    });
    const { results } = (await res.json()) as { results: { content: string; source: string }[] };
    const text = results.length
      ? `Related passages in ${docId} that may need review:\n\n` + results.map(r => r.content).join("\n---\n")
      : `No related passages found in ${docId}.`;
    return { content: [{ type: "text" as const, text }] };
  }
);

server.registerTool(
  "notify_owner",
  {
    description: "Log a notification to a document's owner/reviewer (stub — wire up email/Teams later).",
    inputSchema: { docId: z.string(), message: z.string() },
  },
  async ({ docId, message }) => {
    console.error(`NOTIFY ${docId}: ${message}`);
    return { content: [{ type: "text" as const, text: "Logged (stub)." }] };
  }
);

const transport = new StdioServerTransport();
await server.connect(transport);
```
