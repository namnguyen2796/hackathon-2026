# Feature 01 — Apply changes + signoff & baseline promotion

**Applies to:** `doc-hierarchy` (POC 2)
**Builds on:** `hackathon-plan.md` — that stays the base; this file is additive.

Adds two things to the existing detect → trace → suggest → notify chain:
1. A document **owner accepts a suggestion and applies it** to the draft `.docx`.
2. Owners and reviewers **sign off**; once all are in, a **manager approves** and `draft2`
   becomes `baseline2`, with `current-baseline.txt` repointed.

---

## Design decisions

- **`apply_change` is a literal find-and-replace, not model-authored rewriting.** The owner
  approves a specific old→new text pair and the tool applies exactly that; it errors out if
  the old text isn't found rather than guessing. An LLM freely editing a signed-off
  engineering document is the one thing a safety-critical team would never accept.
  Known limitation: Word splits visible phrases across `<w:r>` runs, so a long fragment may
  not exist contiguously in `document.xml` — the error says to try a shorter fragment. (Docs
  generated by docx-js, like the samples, aren't fragmented, so this works out of the box.)
- **Promotion is guarded, not a rename button.** `approve_baseline` refuses while any changed
  doc lacks owner *or* reviewer signoff. Only then does it rename the draft to the next
  `baselineN` and repoint `current-baseline.txt`.
- **`signoffs.json` lives in the draft folder**, so when the draft is promoted it freezes
  alongside the docs as an audit record of who approved what.
- **"Changed" is determined by byte comparison** against the current baseline, so
  `apply_change` *adds* a doc to the pending-signoff list. Editing `CMP-SIG-101` makes it
  differ from baseline, so it now needs its own owner + reviewer signoff. Correct behaviour
  for change control — but it means the demo needs a signoff per doc you touch.
- **No real auth.** Roles are strings a caller asserts. Fine for a POC; would need identity
  before anyone relied on it.

## `metadata.ts` (new — extracted from `ingest.ts`)

```ts
import mammoth from "mammoth";

export type DocMeta = { docId: string; owner: string; reviewer: string; dependsOn: string[] };

// Every doc starts with a Field | Value table: Document ID, Title, Owner,
// Reviewer, Depends On, Signoff Date, Status.
export async function readMetadata(filePath: string): Promise<DocMeta> {
  const { value: html } = await mammoth.convertToHtml({ path: filePath });
  const rows = [...html.matchAll(/<tr>(.*?)<\/tr>/gs)].map(m =>
    [...m[1].matchAll(/<td[^>]*>(.*?)<\/td>/gs)].map(c => c[1].replace(/<[^>]+>/g, "").trim())
  );
  const map = Object.fromEntries(rows.map(([k, v]) => [k, v]));
  return {
    docId: map["Document ID"],
    owner: map["Owner"],
    reviewer: map["Reviewer"],
    dependsOn: map["Depends On"] === "—" ? [] : map["Depends On"].split(",").map(s => s.trim()),
  };
}
```

**Corresponding change to `ingest.ts`** — delete its inline `parseMetadata`, then:

## `applyChange.ts` (new)

```ts
import AdmZip from "adm-zip";

function escapeXml(s: string) {
  return s.replace(/&/g, "&amp;").replace(/</g, "&lt;").replace(/>/g, "&gt;");
}

export function applyChange(filePath: string, oldText: string, newText: string): string {
  const zip = new AdmZip(filePath);
  const entry = zip.getEntry("word/document.xml");
  if (!entry) throw new Error("Not a valid .docx (no word/document.xml)");
  const xml = zip.readAsText(entry);

  const target = escapeXml(oldText);
  if (!xml.includes(target)) {
    // Word often splits a visible phrase across multiple <w:r> runs, so the
    // text you can see may not exist as one contiguous string in the XML.
    throw new Error(
      `Could not find that exact text in ${filePath}. It may be split across ` +
      `formatting runs — try a shorter, unbroken fragment.`
    );
  }

  zip.updateFile(entry, Buffer.from(xml.split(target).join(escapeXml(newText)), "utf-8"));
  zip.writeZip(filePath);
  return `Applied to ${filePath}: "${oldText}" → "${newText}"`;
}
```

## `signoff.ts` (new)

```ts
import fs from "node:fs";
import path from "node:path";
import { PROJECT_ROOT, getCurrentBaselineDir } from "./currentBaseline.js";
import { readMetadata } from "./metadata.js";

export type SignoffState = {
  draft: string;
  signoffs: { docId: string; name: string; role: "owner" | "reviewer"; date: string }[];
  approval: { manager: string; date: string } | null;
};

const statePath = (draftDir: string) => path.join(draftDir, "signoffs.json");

export function loadState(draftDir: string): SignoffState {
  const p = statePath(draftDir);
  if (!fs.existsSync(p)) {
    return { draft: path.basename(draftDir), signoffs: [], approval: null };
  }
  return JSON.parse(fs.readFileSync(p, "utf-8"));
}

function saveState(draftDir: string, state: SignoffState) {
  fs.writeFileSync(statePath(draftDir), JSON.stringify(state, null, 2));
}

export function recordSignoff(draftDir: string, docId: string, name: string, role: "owner" | "reviewer") {
  const state = loadState(draftDir);
  if (state.signoffs.some(s => s.docId === docId && s.role === role)) {
    return `${docId} already has a ${role} signoff.`;
  }
  state.signoffs.push({ docId, name, role, date: new Date().toISOString().slice(0, 10) });
  saveState(draftDir, state);
  return `Recorded ${role} signoff for ${docId} by ${name}.`;
}

/** Docs whose content differs from the current baseline — these need signoff. */
export async function pendingSignoffs(draftDir: string) {
  const state = loadState(draftDir);
  const baselineDir = getCurrentBaselineDir();
  const out: { docId: string; owner: string; reviewer: string; needs: string[] }[] = [];

  for (const f of fs.readdirSync(draftDir).filter(f => f.endsWith(".docx"))) {
    const draftFile = path.join(draftDir, f);
    const baseFile = path.join(baselineDir, f);
    const changed = !fs.existsSync(baseFile) ||
      !fs.readFileSync(draftFile).equals(fs.readFileSync(baseFile));
    if (!changed) continue;

    const meta = await readMetadata(draftFile);
    const have = state.signoffs.filter(s => s.docId === meta.docId).map(s => s.role);
    const needs = (["owner", "reviewer"] as const).filter(r => !have.includes(r));
    if (needs.length) out.push({ docId: meta.docId, owner: meta.owner, reviewer: meta.reviewer, needs });
  }
  return out;
}

/** Manager approval — refuses while any signoff is outstanding. */
export async function approveAndPromote(draftDir: string, manager: string) {
  const pending = await pendingSignoffs(draftDir);
  if (pending.length) {
    const lines = pending.map(p => `  ${p.docId}: awaiting ${p.needs.join(" + ")}`).join("\n");
    throw new Error(`Cannot approve — signoffs still outstanding:\n${lines}`);
  }

  const state = loadState(draftDir);
  state.approval = { manager, date: new Date().toISOString().slice(0, 10) };
  saveState(draftDir, state);

  // Next free baseline number, then freeze: rename + repoint.
  const docsDir = path.join(PROJECT_ROOT, "docs");
  const used = fs.readdirSync(docsDir)
    .map(d => /^baseline(\d+)$/.exec(d)?.[1])
    .filter(Boolean).map(Number);
  const next = `baseline${Math.max(0, ...used) + 1}`;

  fs.renameSync(draftDir, path.join(docsDir, next));
  fs.writeFileSync(path.join(PROJECT_ROOT, "current-baseline.txt"), next + "\n");
  return `Approved by ${manager}. Promoted to ${next}; current-baseline.txt updated. ` +
         `Re-run 'npx tsx src/ingest.ts' to index the new baseline.`;
}
```

## `mcpServer.ts` — added imports and tools

```ts
import { applyChange } from "./applyChange.js";
import { recordSignoff, pendingSignoffs, approveAndPromote } from "./signoff.js";
// resolveDocPath is already imported in the base plan
```

```ts
server.registerTool(
  "apply_change",
  {
    description: "Apply an owner-approved text change to a draft document. Requires the exact " +
                 "existing text and its replacement — this does not rewrite the document freely.",
    inputSchema: {
      filePath: z.string().describe("Path to the DRAFT .docx to edit"),
      oldText: z.string().describe("Exact existing text to replace"),
      newText: z.string().describe("Replacement text"),
    },
  },
  async ({ filePath, oldText, newText }) => {
    try {
      const msg = applyChange(resolveDocPath(filePath), oldText, newText);
      return { content: [{ type: "text" as const, text: msg }] };
    } catch (e) {
      return { content: [{ type: "text" as const, text: (e as Error).message }], isError: true };
    }
  }
);

server.registerTool(
  "signoff",
  {
    description: "Record an owner or reviewer signoff on a changed draft document.",
    inputSchema: {
      docId: z.string(),
      name: z.string().describe("Person signing off"),
      role: z.enum(["owner", "reviewer"]),
      draftDir: z.string().default("docs/draft2"),
    },
  },
  async ({ docId, name, role, draftDir }) => ({
    content: [{ type: "text" as const, text: recordSignoff(resolveDocPath(draftDir), docId, name, role) }],
  })
);

server.registerTool(
  "signoff_status",
  {
    description: "List changed draft documents still awaiting owner or reviewer signoff.",
    inputSchema: { draftDir: z.string().default("docs/draft2") },
  },
  async ({ draftDir }) => {
    const pending = await pendingSignoffs(resolveDocPath(draftDir));
    const text = pending.length
      ? pending.map(p => `${p.docId} — awaiting ${p.needs.join(" + ")} (owner: ${p.owner}, reviewer: ${p.reviewer})`).join("\n")
      : "All changed documents are fully signed off. Ready for manager approval.";
    return { content: [{ type: "text" as const, text }] };
  }
);

server.registerTool(
  "approve_baseline",
  {
    description: "Manager final approval: promotes the draft to the next baseline and repoints " +
                 "current-baseline.txt. Refuses while any signoff is outstanding.",
    inputSchema: { manager: z.string(), draftDir: z.string().default("docs/draft2") },
  },
  async ({ manager, draftDir }) => {
    try {
      const msg = await approveAndPromote(resolveDocPath(draftDir), manager);
      return { content: [{ type: "text" as const, text: msg }] };
    } catch (e) {
      return { content: [{ type: "text" as const, text: (e as Error).message }], isError: true };
    }
  }
);
```

The last one **refuses** the first time, with signoffs outstanding — show that deliberately.
A workflow tool that can't say no isn't a workflow tool. Then collect the remaining signoffs
and re-run it.

**Back up `docs/` before demoing.** `approve_baseline` really does rename `draft2` →
`baseline2` and rewrite `current-baseline.txt`, so a successful run is not repeatable
without restoring the sample folder.
